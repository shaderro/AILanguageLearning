# 语法与词汇知识点自动检测

## 目标

用户输入一段文字后，分析其中的语法难点和重点词汇（含搭配、短语），生成项目现有格式的知识点数据，并提供原句高亮位置。第一阶段只接入 `MainAssistant`，暂不做前端。

## 当前基础

- 主项目已有 `GrammarRule`、`VocabExpression` 等知识点结构，以及语法 `marked_token_ids`、词汇 `token_indices` 等定位字段。
- `MainAssistant` 已有问答场景下的语法/词汇总结、查重、保存和标注逻辑。
- `preprocessing_knowledge` 有语法分析 agent 和基于 hard token 生成词汇的原型，可作为参考。

## 当前缺口

- `MainAssistant` 目前面向单句问答和用户选区，不支持直接分析整段输入。
- 主流程中的语法功能由 `DISABLE_GRAMMAR_FEATURES = True` 关闭。
- 新原型的语法分析只返回讲解和关键词，缺少主项目所需的规范化规则字段及高亮索引。
- 新原型的词汇流程主要从单个 hard token 生成解释，尚不能稳定识别搭配和短语，也未完整接入主项目数据结构。
- 两类分析都需要输出可验证的 token/文本区间，才能准确高亮原句。
- 新原型含硬编码模型凭证；接入前应撤销并轮换，改用安全配置。

## 实现待办

1. 定义整段文本分析入口及统一返回格式。
2. 让语法分析生成 `GrammarRule` 所需字段，并为每个规则返回对应原文 token 索引。
3. 让词汇分析识别单词、搭配和短语，生成 `VocabExpression` 及 `token_indices`。
4. 校验模型输出、索引边界和重复知识点，并转换为主项目 DTO。
5. 将独立分析流程接入 `MainAssistant`，与现有问答流程兼容；暂不接前端。
6. 清理模型调用凭证配置，并验证端到端输出结构和高亮位置。
